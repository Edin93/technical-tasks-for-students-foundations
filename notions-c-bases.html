Les bases du langage C

1. Variables, caractères et constantes

Une variable est un emplacement nommé qui contient une valeur. Son type indique quelle sorte de valeur elle peut stocker. En C, on déclare une variable avant de l’utiliser.

#include <stdio.h>

int main(void) {
    int age = 20;
    char initiale = 'L';
    const int LIMITE = 100;

    printf("Âge : %d\n", age);
    printf("Initiale : %c\n", initiale);
    printf("Limite : %d\n", LIMITE);
    return 0;
}
  • int représente un nombre entier, par exemple 20 ou -3
  • char représente un caractère, écrit entre apostrophes simples, par exemple 'L'
  • const indique qu’une valeur ne doit pas être modifiée après son initialisation
  • Choisis des noms explicites et initialise les variables avant de lire leur valeur

À distinguer : 'A' est un caractère. La chaîne de caractères "A" contient ce caractère puis le marqueur de fin \0.

2. Afficher des valeurs avec printf

printf affiche du texte et peut insérer des valeurs à l’aide de spécificateurs. Chaque spécificateur doit correspondre au type de la valeur fournie.

\n provoque un retour à la ligne. Le texte de format et les valeurs doivent rester dans le même ordre : par exemple, %d reçoit ici nombre.

3. Tableaux à une et deux dimensions

Tableau d’entiers

Un tableau stocke plusieurs valeurs du même type. Les indices commencent à 0 : le premier élément est valeurs[0].

#include <stdio.h>

int main(void) {
    int valeurs[] = {4, 7, 2, 9};
    int nombreElements = (int)(sizeof valeurs / sizeof valeurs[0]);

    for (int i = 0; i < nombreElements; i++) {
        printf("Élément %d : %d\n", i, valeurs[i]);
    }
    return 0;
}

sizeof valeurs donne la taille totale du tableau en octets. En la divisant par la taille d’un élément, on obtient son nombre d’éléments. Cette méthode s’applique ici parce que valeurs est un vrai tableau dans cette fonction.

Tableau de caractères

Une chaîne C est un tableau de caractères qui se termine par le caractère spécial \0. Les guillemets doubles servent à écrire une chaîne.

char mot[] = "chat";
printf("%s\n", mot);
printf("Première lettre : %c\n", mot[0]);

Tableau à deux dimensions

Un tableau à deux dimensions peut représenter une grille. On utilise un indice pour la ligne et un autre pour la colonne.

#include <stdio.h>

int main(void) {
    int grille[2][3] = {{1, 2, 3}, {4, 5, 6}};

    for (int ligne = 0; ligne < 2; ligne++) {
        for (int colonne = 0; colonne < 3; colonne++) {
            printf("%d ", grille[ligne][colonne]);
        }
        printf("\n");
    }
    return 0;
}

Un tableau de caractères à deux dimensions peut contenir plusieurs mots de longueur maximale fixée :

char animaux[2][10] = {"chat", "chien"};
printf("%s\n", animaux[0]);
printf("%s\n", animaux[1]);

4. Conditions : if, else if et else

Une condition permet d’exécuter un bloc seulement si une expression est vraie. else if ajoute un autre cas et else décrit le cas restant.

#include <stdio.h>

int main(void) {
    int note = 14;

    if (note < 0 || note > 20) {
        printf("Note invalide\n");
    } else if (note >= 10) {
        printf("Réussi\n");
    } else {
        printf("À retravailler\n");
    }
    return 0;
}
  • == teste l’égalité, tandis que = affecte une valeur à une variable
  • !=, <, >, <= et >= sont des opérateurs de comparaison
  • && signifie « et », || signifie « ou », et ! inverse une condition
  • % donne le reste d’une division entière : nombre % 2 == 0 teste si le nombre est pair

5. Boucles : for, while et boucles imbriquées

Boucle for

Utilise souvent for quand le nombre de répétitions est connu. Les trois parties indiquent l’initialisation, la condition de continuation et la mise à jour.

for (int i = 1; i <= 5; i++) {
    printf("%d\n", i);
}

Boucle while

Utilise souvent while quand la répétition dépend d’une condition. Pense à modifier la variable de contrôle pour que la boucle puisse se terminer.

int compteur = 1;
while (compteur <= 5) {
    printf("%d\n", compteur);
    compteur++;
}

Boucles imbriquées

Une boucle imbriquée est une boucle placée dans une autre. Elle sert notamment à parcourir une grille ou à dessiner une forme ligne par ligne.

for (int ligne = 1; ligne <= 3; ligne++) {
    for (int colonne = 1; colonne <= 5; colonne++) {
        printf("*");
    }
    printf("\n");
}

6. Fonctions simples

Une fonction regroupe des instructions sous un nom. Elle peut recevoir des paramètres et renvoyer une valeur. Une fonction de type void ne renvoie pas de valeur.

Sans paramètre et sans valeur de retour

void afficherBonjour(void) {
    printf("Bonjour !\n");
}

int main(void) {
    afficherBonjour();
    return 0;
}

Le premier void indique que la fonction ne renvoie rien. Le void entre parenthèses indique qu’elle ne reçoit aucun paramètre.

Avec paramètres et sans valeur de retour

void afficherRectangle(int largeur, int hauteur) {
    for (int ligne = 0; ligne < hauteur; ligne++) {
        for (int colonne = 0; colonne < largeur; colonne++) {
            printf("*");
        }
        printf("\n");
    }
}

int main(void) {
    afficherRectangle(5, 3);
    return 0;
}

Les valeurs 5 et 3 sont transmises aux paramètres largeur et hauteur. La fonction affiche la forme et ne renvoie aucune valeur.

Avec paramètres et valeur de retour

int maximum(int a, int b) {
    if (a > b) {
        return a;
    }
    return b;
}

int main(void) {
    int resultat = maximum(12, 7);
    printf("Maximum : %d\n", resultat);
    return 0;
}

return renvoie le résultat à l’endroit où la fonction a été appelée. La fonction peut ensuite être utilisée dans une affectation ou une expression.

7. Exercices classiques et démonstrations

Afficher les nombres de 0 à 100

for (int i = 0; i <= 100; i++) {
    printf("%d ", i);
}
printf("\n");

La condition i <= 100 inclut la valeur 100.

Afficher les nombres pairs de 0 à 100

for (int i = 0; i <= 100; i += 2) {
    printf("%d ", i);
}
printf("\n");

Comme on commence à 0 et qu’on ajoute 2 à chaque tour, chaque valeur affichée est paire.

FizzBuzz

On teste d’abord la divisibilité par 3 et 5 ensemble. Sinon, le cas divisible par 3 serait traité avant celui de 5 et afficherait seulement Fizz pour 15.

for (int i = 1; i <= 15; i++) {
    if (i % 3 == 0 && i % 5 == 0) {
        printf("FizzBuzz\n");
    } else if (i % 3 == 0) {
        printf("Fizz\n");
    } else if (i % 5 == 0) {
        printf("Buzz\n");
    } else {
        printf("%d\n", i);
    }
}

Vérifier un palindrome

Cette version compare les caractères symétriques. Elle considère les majuscules différentes des minuscules et ne retire ni espaces ni ponctuation.

int estPalindrome(const char mot[]) {
    int longueur = 0;
    while (mot[longueur] != '\0') {
        longueur++;
    }

    for (int i = 0; i < longueur / 2; i++) {
        if (mot[i] != mot[longueur - 1 - i]) {
            return 0;
        }
    }
    return 1;
}

int main(void) {
    char mot[] = "radar";
    if (estPalindrome(mot)) {
        printf("%s est un palindrome.\n", mot);
    } else {
        printf("%s n'est pas un palindrome.\n", mot);
    }
    return 0;
}

La fonction renvoie 1 si le mot est un palindrome et 0 sinon. main utilise cette valeur dans une condition.

Rectangle de largeur variable

La même logique de boucles imbriquées dessine un rectangle : remplace la limite de colonnes par la largeur et celle des lignes par la hauteur.

int largeur = 8;
int hauteur = 3;
for (int ligne = 0; ligne < hauteur; ligne++) {
    for (int colonne = 0; colonne < largeur; colonne++) {
        printf("*");
    }
    printf("\n");
}

Conseils pour vérifier un programme

  • Compile avec les avertissements activés : gcc -std=c11 -Wall -Wextra fichier.c -o programme
  • Lance ensuite le programme : ./programme
  • Vérifie les limites des boucles, les indices de tableau et les retours à la ligne
  • Compare la sortie réelle à la sortie attendue, caractère par caractère
