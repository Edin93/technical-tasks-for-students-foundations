C • chaînes de caractères

Comprendre les chaînes en C

Un texte en C est une suite de caractères terminée par un marqueur spécial. Nous allons distinguer le tableau de caractères qui contient le texte du pointeur qui indique où il se trouve.

01

Un mot est une rangée de caractères

Dans un tableau de caractères, chaque case contient une lettre. La fin du texte est signalée par le caractère nul '\0'. Il ne s’agit pas du chiffre zéro : c’est un caractère de contrôle qui marque la fin.

🔖

Image mentale : le marqueur '\0' est un signet placé après la dernière lettre pour dire « le texte s’arrête ici ».

Les défis 8 à 12 travaillent les chaînes, leur longueur, les voyelles et le parcours par pointeur.

02

La chaîne inclut un caractère de fin

Les guillemets doubles créent une chaîne. Le compilateur réserve aussi une case pour le marqueur de fin. Ainsi, le mot "chat" occupe cinq cases.

Exemple de tableau
char mot[] = "chat";
printf("%s\n", mot);
printf("%c\n", mot[1]);
Cases en mémoire
indice :  0   1   2   3   4
valeur : 'c' 'h' 'a' 't' '\0'

%s lit les caractères jusqu’à '\0'; %c affiche un seul caractère.

Sortiechat
h

Pour obtenir une longueur avec strlen, ajoute #include <string.h>. La longueur exclut le marqueur de fin. Si tu parcours toi-même, arrête-toi dès que le caractère vaut '\0'.

Erreur fréquente : une chaîne de quatre lettres a besoin d’au moins cinq cases si tu construis toi-même le tableau.

QCM · Combien de cases faut-il pour stocker "chat" ?

Vrai ou faux · '\0' fait partie du stockage d’une chaîne C.

Clique sur une case de "chat"

La dernière case marque la fin de la chaîne.

03

Tableau modifiable et pointeur vers du texte

Ces deux déclarations ne font pas la même chose. mot est un tableau qui contient une copie modifiable des caractères. lecture est un pointeur qui désigne un texte constant.

Tableau modifiable
char mot[] = "chat";
mot[0] = 'C';
printf("%s\n", mot);

Sortie : Chat. Les caractères du tableau peuvent être modifiés.

Pointeur vers un texte constant
const char *lecture = "chat";
printf("%s\n", lecture);
lecture = "chien";

Le pointeur peut désigner un autre texte. Le texte pointé ne doit pas être modifié.

char *p = mot; crée un pointeur vers le tableau modifiable mot. Tu peux changer le caractère désigné par *p. À l’inverse, ne tente jamais d’écrire dans une chaîne littérale comme "chat".

Bon réflexe : écris const char *texte pour lire une chaîne littérale. Cela exprime clairement qu’elle n’est pas modifiable.

QCM · Quelle déclaration convient pour lire le texte littéral "Salut" sans le modifier ?

Vrai ou faux · Le tableau char mot[] = "chat"; ne peut pas être modifié.

04

Parcourir une chaîne avec un indice ou un pointeur

Un indice choisit directement une case. Un pointeur peut avancer d’un caractère à la fois. Dans les deux cas, il faut s’arrêter à '\0'.

Avec un indice
int i;
for (i = 0; mot[i] != '\0'; i++) {
    printf("%c", mot[i]);
}
Avec un pointeur
const char *p;
p = "C facile";
while (*p != '\0') {
    printf("%c", *p);
    p++;
}

p est une adresse de caractère; *p est le caractère à cette adresse. L’opération p++ avance au caractère suivant. Ne fais pas p++ sur le nom d’un tableau.

Sortie du second exempleC facile

Pour compter des voyelles, examine chaque caractère, compare-le à 'a', 'e', 'i', 'o' et 'u', puis augmente un compteur.

QCM · Que désigne *p ?

Vrai ou faux · Une boucle de parcours s’arrête quand elle rencontre '\0'.

Résumé à retenir

  • Une chaîne C est un tableau de caractères terminé par '\0'.
  • char mot[] stocke une copie modifiable; const char *texte désigne un texte à lire.
  • *p lit le caractère pointé; p++ avance le pointeur.
  • N’écris jamais dans une chaîne littérale.
