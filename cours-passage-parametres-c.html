C • fonctions et paramètres

Passage par valeur et par adresse

Une fonction reçoit des paramètres pour travailler. Comprendre si elle reçoit une copie ou l’adresse d’une variable explique pourquoi certaines modifications restent locales et d’autres touchent la variable de départ.

01

La fonction reçoit une information en entrée

Dans un appel de fonction, l’argument est la valeur envoyée. Le paramètre est la variable locale qui reçoit cette valeur dans la fonction.

📄

Image mentale : passer un entier par valeur, c’est donner une photocopie du nombre. La fonction peut écrire sur sa copie sans changer l’original.

En C, tous les arguments sont transmis par valeur. Même lorsqu’on utilise un pointeur, c’est la valeur de l’adresse qui est copiée dans le paramètre.

02

Le passage par valeur modifie seulement la copie

Syntaxe
void mettreAZero(int nombre) {
    nombre = 0;
}
Appel et observation
int score;

score = 7;
mettreAZero(score);
printf("%d\n", score);

La sortie est 7, car seule la copie locale nombre a changé.

Au retour de la fonction, son paramètre local disparaît. La variable de main reste inchangée.

QCM · Que vaut score après mettreAZero(score) ?

Vrai ou faux · Un paramètre int nombre reçoit une copie de l’entier envoyé.

03

Pour modifier l’original, transmettre son adresse

On passe l’adresse avec &. La fonction reçoit cette adresse dans un paramètre pointeur, puis utilise * pour accéder à la variable d’origine.

Fonction qui modifie
void ajouterUn(int *nombre) {
    *nombre = *nombre + 1;
}
Appel de la fonction
int score;

score = 10;
ajouterUn(&score);
printf("%d\n", score);

Sortie : 11.

On appelle souvent cela « passage par référence » dans les cours introductifs. Pour être précis, C transmet toujours par valeur : la valeur copiée est ici une adresse. Grâce à cette adresse, la fonction peut atteindre l’objet original.

Une fonction peut aussi utiliser plusieurs pointeurs, par exemple echanger(int *a, int *b), afin de modifier deux variables appelantes.

Attention : le terme « par référence » est une façon pratique de parler de l’effet obtenu; le langage C n’a pas de paramètres référence comme C++.

QCM · Pourquoi appelle-t-on ajouterUn(&score) ?

Vrai ou faux · C possède un véritable mécanisme de paramètres passés par référence.

Compare les deux appels

Valeur de la variable avant l’appel : 7

Choisis un appel pour comparer la copie et la modification par pointeur.

04

Un tableau en paramètre : transmettre aussi sa taille

Quand un tableau est utilisé comme paramètre, la fonction reçoit l’adresse de sa première case. Elle ne reçoit pas une copie complète avec sa taille. Il faut donc ajouter un paramètre de taille.

int sommeTableau(const int valeurs[], int taille) {
    int i;
    int somme;

    somme = 0;
    for (i = 0; i < taille; i++) {
        somme = somme + valeurs[i];
    }
    return somme;
}

Le mot const indique que cette fonction lit les cases sans les modifier. Pour un tableau 2D, le nombre de colonnes doit aussi être précisé dans le paramètre, par exemple int grille[][3].

Pour modifier les éléments, un paramètre tableau non-const suffit. Pour modifier le pointeur appelant lui-même, il faut recevoir son adresse sous forme de pointeur vers pointeur.

QCM · Pourquoi ajouter taille à la fonction ?

Vrai ou faux · const int valeurs[] sert à protéger les valeurs contre une modification par cette fonction.

05

Changer la cible d’un pointeur reçu

Un paramètre int *p est une copie du pointeur de l’appelant. Modifier *p change l’entier désigné, mais réaffecter p seul ne change pas le pointeur d’origine. Pour changer ce dernier, il faut transmettre son adresse : int **.

void changerCible(int **p, int *nouvelleCible) {
    *p = nouvelleCible;
}

À l’appel, on fournit &pointeur. Dans la fonction, *p représente alors le pointeur d’origine; lui affecter une nouvelle adresse change sa cible.

QCM · Quel paramètre permet à une fonction de changer le pointeur de l’appelant ?

Vrai ou faux · Un paramètre int *p suffit pour changer le pointeur de l’appelant.

Résumé à retenir

  • En C, tout argument est transmis par valeur.
  • Un pointeur reçu par valeur permet de modifier l’objet pointé via *p.
  • On transmet &variable pour donner l’adresse de la variable.
  • Un paramètre int ** permet de modifier le pointeur de l’appelant.
  • Pour un tableau, passe aussi sa taille; pour une matrice, précise le nombre de colonnes.
