C • pointeurs

Comprendre les pointeurs

Un pointeur est une variable qui stocke une adresse. Nous allons apprendre à lire cette adresse, à accéder à la valeur qui s’y trouve, puis à comprendre les pointeurs vers pointeurs.

Adresse mémoire* et &int **
← Cours précédent : chaînesCours suivant : fonctions →
01

Une adresse indique où se trouve une valeur

Chaque variable occupe une place en mémoire. Un pointeur contient l’adresse de cette place. L’opérateur & demande l’adresse d’une variable. L’opérateur *, lorsqu’il est utilisé sur un pointeur valide, accède à la valeur située à cette adresse.

🏠

Image mentale : la variable est une maison, son adresse est le pointeur, et *p signifie « entre dans la maison indiquée par p pour lire ou modifier ce qu’elle contient ».

02

Déclarer un pointeur et le déréférencer

Le type du pointeur indique le type de valeur qu’il peut désigner. int *p signifie que p est un pointeur vers un entier.

Syntaxe et exemple
int score;
int *p;

score = 42;
p = &score;
printf("Valeur : %d\n", *p);
*p = 50;
printf("Nouveau score : %d\n", score);
À chaque expression
  1. p = &score range l’adresse de score dans p
  2. *p lit ou modifie la valeur de score
  3. Après l’affectation, score vaut 50
SortieValeur : 42
Nouveau score : 50

Attention au contexte : dans int *p, l’astérisque fait partie de la déclaration. Dans *p = 50, il signifie « valeur pointée ».

QCM · Que fait p = &score ?

Vrai ou faux · *p = 50; peut modifier la variable désignée par p.

03

Un pointeur doit viser une case valide

Un pointeur non initialisé contient une adresse inconnue. Le déréférencer peut faire planter le programme ou modifier une zone mémoire imprévisible. Quand tu n’as pas encore de cible, initialise-le à NULL.

#include <stddef.h>
#include <stdio.h>

int main(void) {
    int *p;

    p = NULL;
    if (p != NULL) {
        printf("%d\n", *p);
    }
    return 0;
}

Ici, le bloc ne s’exécute pas. Avant d’utiliser *p, assure-toi que p pointe vers un objet qui existe encore.

Ne confonds pas NULL avec une valeur entière du tableau. Il représente l’absence d’adresse utilisable.

QCM · Que signifie généralement p = NULL ?

Vrai ou faux · On peut lire *p lorsque p == NULL.

04

Parcourir un tableau avec un pointeur

Le nom d’un tableau peut servir à obtenir l’adresse de sa première case. Si p pointe dans un tableau, p + 1 désigne l’élément suivant du même tableau.

int nombres[3] = {10, 20, 30};
int *p;
int i;

p = nombres;
for (i = 0; i < 3; i++) {
    printf("%d ", *(p + i));
}
Sortie10 20 30

p[i] et *(p + i) accèdent à la même case. Ne déplace pas le pointeur au-delà des limites pour lire une valeur.

QCM · Si p désigne nombres[0], que désigne p + 1 ?

Vrai ou faux · *(p + i) peut lire le iᵉ élément depuis la position de départ de p.

05

Un pointeur vers un pointeur

Un int **pp est un pointeur vers un pointeur vers un entier. Il contient l’adresse d’une variable de type int *.

Trois niveaux
int valeur;
int *p;
int **pp;

valeur = 42;
p = &valeur;
pp = &p;
printf("%d\n", **pp);
Lire les étoiles
  1. pp désigne le pointeur p
  2. *pp est le pointeur p
  3. **pp est la valeur 42

Ce niveau supplémentaire sert, par exemple, lorsqu’une fonction doit changer la cible d’un pointeur reçu. Il n’est pas nécessaire pour modifier directement un entier : un simple int * suffit.

Repère : chaque * enlève un niveau d’adresse. Vérifie le type de chaque variable avant d’ajouter une étoile.

QCM · Que contient **pp dans l’exemple ?

Vrai ou faux · int **pp pointe directement sur un entier.

Résumé à retenir

  • &variable donne une adresse; *p accède à la valeur pointée.
  • Avant de déréférencer, assure-toi que le pointeur a une cible valide.
  • Pour un tableau, p + 1 désigne l’élément suivant.
  • int **pp pointe vers un pointeur int *.
