Comprendre les tableaux en C

Un tableau rassemble plusieurs valeurs de même type. Nous allons voir comment le créer, lire ses cases, le parcourir, puis représenter une grille.

Avant de commencer : une rangée de cases

Imagine une rangée de casiers. Chaque casier a un numéro appelé indice et contient une valeur. En C, les indices commencent à 0.

Image mentale : quatre notes occupent les cases 0, 1, 2 et 3. Il n’existe pas de case 4 dans ce tableau.

02

Déclarer et lire un tableau simple

La déclaration indique le type des éléments, le nom du tableau et le nombre de cases. L’initialisation place les valeurs dans ces cases dès la création.

Syntaxe et exemple
#define NB_NOTES 4

int notes[NB_NOTES] = {12, 15, 9, 18};
printf("Premiere note : %d\n", notes[0]);
printf("Derniere note : %d\n", notes[NB_NOTES - 1]);
Ce que l’on lit
  1. int : chaque case contient un entier
  2. notes[0] vaut 12
  3. La dernière case est à l’indice 3
SortiePremiere note : 12
Derniere note : 18

NB_NOTES décrit le nombre de cases. Le tableau ne mémorise pas sa longueur pour toi : conserve cette information séparément.

Erreur fréquente : lire notes[4]. Dans un tableau de quatre cases, les indices valides sont 0 à 3. Sortir de ces limites produit un comportement indéfini.

QCM · Quels sont les indices valides de int notes[4] ?

Vrai ou faux · notes[0] est le premier élément.

03

Parcourir un tableau et le donner à une fonction

Une boucle for est pratique quand le nombre de cases est connu. On commence à 0 et on continue tant que l’indice est inférieur à la taille.

int i;
int somme;

somme = 0;
for (i = 0; i < NB_NOTES; i++) {
    somme = somme + notes[i];
}
printf("Somme : %d\n", somme);

La boucle visite 0, 1, 2 et 3. Dans une fonction, un paramètre écrit int valeurs[] se comporte comme un pointeur vers la première case; il faut donc transmettre la taille séparément.

int sommeTableau(const int valeurs[], int taille);

const indique ici que la fonction ne doit pas modifier les cases reçues.

Somme obtenueSomme : 54

À retenir : écris i < taille, pas i <= taille, afin de ne pas lire une case après la fin.

QCM · Quelle condition parcourt toutes les cases sans dépasser la fin ?

Vrai ou faux · Une fonction connaît automatiquement la taille du tableau reçu.

04

Représenter une grille avec un tableau à deux dimensions

Un tableau 2D est une grille de lignes et de colonnes. Il faut deux indices : le premier choisit la ligne, le second la colonne.

Déclaration et lecture
#define LIGNES 2
#define COLONNES 3

int grille[LIGNES][COLONNES] = {
    {1, 2, 3},
    {4, 5, 6}
};
printf("%d\n", grille[1][2]);
Déroulement
  1. grille[1] choisit la deuxième ligne
  2. grille[1][2] choisit sa troisième colonne
  3. La valeur affichée est 6

On parcourt les lignes avec une boucle extérieure et les colonnes avec une boucle intérieure. Dans une fonction, la largeur doit être connue, par exemple int valeurs[][3].

Sortie6

Erreur fréquente : intervertir ligne et colonne ou oublier qu’elles commencent toutes les deux à 0.

QCM · Quelle valeur contient grille[1][2] ?

Vrai ou faux · Une boucle intérieure peut parcourir les colonnes de chaque ligne.

Résumé à retenir

  • Les indices commencent à 0.
  • Le nombre d’éléments et le dernier indice sont différents : dernier indice = taille - 1.
  • Pour une grille, utilise grille[ligne][colonne].
  • Une fonction reçoit la taille d’un tableau séparément.
