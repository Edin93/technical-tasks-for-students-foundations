01

Un programme C commence dans main

Un programme est une liste d’instructions. Quand tu le lances, l’exécution commence dans la fonction main. Dans nos programmes, return 0 indique qu’ils se sont terminés correctement.

🚪

Image mentale : main est la porte d’entrée. Le programme commence là, puis suit les instructions dans l’ordre.

Syntaxe minimale
#include <stdio.h>

int main(void) {
    printf("Bonjour !\n");
    return 0;
}
Lecture
  1. stdio.h permet d’utiliser printf
  2. Le programme entre dans main
  3. Le message s’affiche
  4. return 0 termine main

QCM · Où commence l’exécution ?

Vrai ou faux · return 0 termine main.

02

Déclarer, initialiser, puis modifier

Déclarer, c’est annoncer qu’une variable existe et préciser son type. Initialiser, c’est lui donner sa première valeur. Une affectation peut ensuite remplacer cette valeur.

📦

Image mentale : déclarer, c’est poser une boîte étiquetée « score ». Initialiser, c’est mettre 0 dedans. Affecter 8 ensuite, c’est remplacer le contenu.

Trois moments
int score;       /* déclaration */
score = 0;       /* initialisation */
score = 8;       /* nouvelle affectation */
En une ligne
int vies = 3;

Cette ligne déclare vies et l’initialise à 3.

Une variable locale non initialisée n’a pas de valeur utilisable garantie. Donne-lui une valeur avant de la lire.

Manipule la boîte « score »

Choisis une étape pour voir son état mémoire.

Pas encore déclarée—

Commence par déclarer la variable.

QCM · Que fait int score; ?

Vrai ou faux · Après int score;, score vaut toujours 0.

printf : afficher du texte et des valeurs

printf écrit à l’écran. Les codes du texte de format sont remplacés par les valeurs placées après la virgule, dans le même ordre.

FormatType affichéExemple%dintentier%ldlong intentier long%ffloat12.500000%.2ffloat12.50%ccharune lettre%schaîneun mot
int points = 12;
char lettre = 'C';
printf("Points : %d\nLettre : %c\n", points, lettre);
TerminalPoints : 12
Lettre : C

\n fait passer à la ligne suivante. Avec printf, un float est automatiquement converti en double pour l’appel, donc %f est correct.

Vrai ou faux · \n fait passer à la ligne suivante.

05

Tableaux : plusieurs cases sous un même nom

Un tableau contient plusieurs valeurs du même type. Les indices commencent à 0. Pour quatre éléments, les indices sont 0, 1, 2 et 3.

int notes[4] = {12, 15, 9, 18};
printf("Première note : %d\n", notes[0]);
printf("Dernière note : %d\n", notes[3]);
indice 0indice 1indice 2indice 3
1215918

Chaîne de caractères

Une chaîne C est un tableau de caractères qui se termine par \0. Les guillemets doubles ajoutent ce marqueur de fin.

char mot[] = "chat";
printf("%s\n", mot);
printf("Première lettre : %c\n", mot[0]);

Tableau à deux dimensions

Un tableau 2D ressemble à une grille. On donne d’abord l’indice de ligne, puis celui de colonne.

int grille[2][3] = {{1, 2, 3}, {4, 5, 6}};
printf("%d\n", grille[1][2]); /* affiche 6 */
🗄️

Image mentale : un tableau simple est une rangée de cases; un tableau 2D est une grille repérée par lignes et colonnes.

QCM · Quel est l’indice du premier élément de notes ?

Vrai ou faux · Pour lire la dernière note, on écrit notes[4].

06

Conditions : choisir quelle instruction exécuter

Une condition pose une question dont la réponse est vraie ou fausse. if teste un cas, else if un autre, et else le cas restant.

int note = 14;
if (note >= 10) {
    printf("Réussi\n");
} else {
    printf("À retravailler\n");
}
Début
↓
note >= 10 ?
OuiAfficher « Réussi »
NonAfficher « À retravailler »
↓
Suite du programme

== teste l’égalité; = affecte une valeur. && signifie « et », || signifie « ou ». L’opérateur % donne le reste d’une division : nombre % 2 == 0 teste si un nombre est pair.

🚦

Image mentale : si le feu est vert (condition vraie), prends une route; sinon, prends l’autre.

QCM · Quel opérateur teste si a vaut 5 ?

Vrai ou faux · else s’exécute lorsque le test du if est faux.

07

Boucles : répéter des instructions

Une boucle répète un bloc tant que sa règle de continuation est vraie. Il faut faire évoluer la variable de contrôle pour que la boucle puisse finir.

for : quand les étapes sont connues

int i;
for (i = 0; i <= 3; i++) {
    printf("%d\n", i);
}

Les trois parties donnent la valeur de départ, la condition avant chaque tour et la mise à jour à la fin du tour.

while : tester avant le tour

int i = 0;
while (i < 4) {
    printf("%d\n", i);
    i++;
}

do while : faire un tour, puis tester

int i = 1;
do {
    printf("%d\n", i);
    i++;
} while (i <= 3);

while peut faire zéro tour. do while fait toujours au moins un tour.

08

break et continue : agir sur une boucle

break sort de la boucle la plus proche. continue saute le reste du tour et passe au suivant.

int i;
for (i = 1; i <= 6; i++) {
    if (i == 3) continue;
    if (i == 5) break;
    printf("%d ", i);
}
Affiché1 2 4

Le tour où i vaut 3 est sauté. Quand i vaut 5, la boucle s’arrête; 6 n’est pas visité.

🚌

Image mentale : continue saute un arrêt; break descend du bus et termine le trajet.

QCM · Pourquoi le 3 n’est-il pas affiché ?

Vrai ou faux · continue quitte définitivement la boucle.

09

Boucles imbriquées : lignes et colonnes

Une boucle imbriquée est placée à l’intérieur d’une autre. Pour chaque tour de la boucle extérieure, la boucle intérieure fait tous ses tours. Cela sert à parcourir une grille ou dessiner une forme.

int ligne;
int colonne;
for (ligne = 0; ligne < 3; ligne++) {
    for (colonne = 0; colonne < 5; colonne++) {
        printf("*");
    }
    printf("\n");
}

La boucle extérieure choisit une ligne. La boucle intérieure dessine les cinq étoiles de cette ligne. Ensuite, printf("\\n") passe à la suivante.

Clique une case pour voir ses indices de ligne et colonne.

QCM · Combien d’étoiles sont affichées au total ?

Vrai ou faux · La boucle intérieure finit avant que la boucle extérieure passe à la ligne suivante.

10

Fonctions : donner un nom à une tâche

Une fonction regroupe des instructions. Elle peut recevoir des paramètres et renvoyer une valeur. Le type placé avant le nom indique ce qu’elle renvoie. void signifie « aucune valeur »; dans les parenthèses, void signifie « aucun paramètre ».

Pas de paramètre, pas de retour
void direBonjour(void) {
    printf("Bonjour !\n");
}

Appel : direBonjour();

Paramètre int, pas de retour
void afficherDouble(int nombre) {
    printf("%d\n", nombre * 2);
}

Appel : afficherDouble(6);

Paramètres et retour int
int additionner(int a, int b) {
    return a + b;
}

Appel : resultat = additionner(3, 4);

Retour char, pas de paramètre
char obtenirLettre(void) {
    return 'M';
}

Appel : lettre = obtenirLettre();

Paramètre et retour char
char choisirLettre(char lettre) {
    return lettre;
}

Appel : lettre = choisirLettre('A');

Une fonction qui renvoie une valeur la transmet avec return. On peut stocker cette valeur, l’afficher ou l’utiliser dans une condition.

🍳

Image mentale : une fonction est une recette. Les paramètres sont les ingrédients; la valeur retournée est le résultat. Une fonction void réalise une action sans rendre de résultat.

QCM · Que signifie le premier void dans void afficher(int nombre) ?

Vrai ou faux · Une fonction int peut renvoyer un entier avec return.

11

Quelques recettes classiques

Compter et filtrer

Pour compter de 0 à 10, augmente un compteur d’une unité. Pour afficher les pairs seulement, augmente-le de 2 ou teste nombre % 2 == 0.

int nombre;
for (nombre = 0; nombre <= 10; nombre++) {
    printf("%d ", nombre);
}

FizzBuzz : tester les cas dans le bon ordre

Teste d’abord le cas divisible par 3 et 5. Sinon, 15 serait déjà classé comme multiple de 3.

if (nombre % 3 == 0 && nombre % 5 == 0) {
    printf("FizzBuzz\n");
} else if (nombre % 3 == 0) {
    printf("Fizz\n");
} else if (nombre % 5 == 0) {
    printf("Buzz\n");
} else {
    printf("%d\n", nombre);
}

Palindrome : comparer les extrémités

Un palindrome se lit pareil dans les deux sens. Compare les caractères qui se font face, puis rapproche-toi du centre. Commence par un mot en minuscules, sans espaces ni ponctuation.

int gauche = 0;
int droite = longueur - 1;
int palindrome = 1;
while (gauche < droite) {
    if (mot[gauche] != mot[droite]) {
        palindrome = 0;
        break;
    }
    gauche++;
    droite--;
}
🪞

Image mentale : un palindrome est comme un miroir : les lettres qui se font face doivent être identiques.

QCM · Pourquoi tester FizzBuzz avant Fizz ?

Vrai ou faux · On peut tester un palindrome en comparant ses deux extrémités.
